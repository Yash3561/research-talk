05 / PROPOSED FIRST PHD STUDY

Learn the model error.
Test whether it helps control.

Research question: can structured model-error estimates improve task completion enough to justify their measurement and computation cost?

State + commands→Predict motion→Observe error→Test a correction→Evaluate decisions
01

Reproduce & diagnose

Start with a lab-relevant baseline and permitted model or logs. Separate numerical, timing and physical failures before attributing them to model error.

First deliverable: baseline reproduction and a failure/error map.
02

Test a useful estimate

If errors are predictable, compare a small learned correction or uncertainty estimate with appropriate nonlearning alternatives.

Test held-out prediction quality, calibration where relevant, and added compute cost.
03

Measure task benefit

Compare against feedback and relevant robust/adaptive baselines with matched information and computation; reserve untouched evaluation cases.

Primary outcomes: completion, constraint violations and deadline misses.

SCIENTIFIC CONTEXT

Methods & publications

Pilot evidence and proposal scope

The proposed model-error learning study is future work. The current pilot contains conventional controllers, supplied actuator estimates and no learned correction or calibrated uncertainty model. It does not establish an advance over M4 or Husky.

All three methods ran on the same 192 cases. The declared primary contrast is capped predictive control minus selected integral feedback. Whole-group resampling preserves the paired cases.

The fresh analysis and both replay audits completed on November 2, 2026. The interrupted earlier run is retained without inference; the completed replacement is the same cohort, not a second independent test.

Current limits: exact simulated sensing, supplied static actuator estimates, one authored plant and no hardware evaluation. Descriptive solver failures do not establish a causal explanation for the negative result.
