02 / THE PHYSICAL QUESTION

Changing the body changes
the control problem.

Can a predictive controller complete a shape-changing maneuver when motors respond differently from its model?

01

Geometry changes force direction.

Tilting the rotor axes changes how much thrust can support the vehicle’s weight.

02

Motor response changes the timing.

A command is bounded, takes effect gradually and must remain useful while a new plan is computed.

Related context: M4 and Husky explore body reconfiguration and ground–aerial movement. This study uses a distinct, simplified model.

05 / PROPOSED NEXT STUDY

Find the mechanism.
Test one justified change.

A useful next contribution is a controlled diagnosis of when predictive control loses to feedback—and whether one targeted change addresses that failure.

01

Diagnose

Separate numerical rejection, command fallback, model mismatch and physical task failures using matched interventions.

Measure: completion, constraint violations, deadline misses.
02

Reproduce

Reproduce a relevant lab or published baseline. Match information and computation before adding identification or adaptation.

Establish: measurement interface, baseline and permitted model or logs.
03

Confirm

Freeze the selected method, reserve new evaluation groups and test on an independent model before physical validation.

Report: paired effects, uncertainty and every failure.

Potential connection: actuator-aware control for reconfigurable robots, or model-error evaluation for contact-rich locomotion.

Which failure case would be most useful to investigate first?

Current stage: exploratory simulation. The fresh result does not establish its cause; novelty and transfer to hardware remain open.

Protocol and evidence

All three methods ran on the same 192 cases. The declared primary contrast is capped predictive control minus selected integral feedback. Whole-group resampling preserves the paired cases.

The fresh analysis and both replay audits completed on November 2, 2026. The interrupted earlier run is retained without inference; the completed replacement is the same cohort, not a second independent test.

Current limits: exact simulated sensing, supplied static actuator estimates, one authored plant and no hardware evaluation. Descriptive solver failures do not establish a causal explanation for the negative result.
